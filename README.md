## 👨‍💻 About Me

I'm a **4th-year B.Tech Computer Science & Engineering student** who is seriously working toward becoming a **full-stack web developer and software engineer**.

Right now, my main focus is **JavaScript and web development**. I'm not trying to just memorize syntax. I want to understand *why* code works, how the browser behaves, and what's happening behind the scenes.

I learn by building small things, getting stuck, debugging, and then writing about it so another beginner doesn't have to struggle as much as I did.
